AutoX.js 是一个 Android 平台上的 JavaScript 自动化工具，可以实现各种自动化操作。

## 特性

- 基于 JavaScript 语法，易于上手
- 支持控件操作、图片识别、OCR 等多种自动化方式
- 丰富的 API，涵盖 UI、文件、网络、多线程等
